# 第九潮汐档案馆：无岸层

一件由《Archive of the Ninth Tide / 第九潮汐档案馆》实时驱动的 Three.js 深海声光装置。音乐不被画成一张频谱图，而被解释为九种物质状态；点击声呐时，整个空间会按当前章节采用不同的传播语法。

## 启动

先在仓库根目录安装精确锁定的 workspace 依赖：

```bash
pnpm install --frozen-lockfile
```

再运行对应脚本（脚本会先构建完整的 `dist/`，再启动本地服务）：

- Windows：`start_windows.bat`
- macOS：`start_macos.command`
- Linux：`start_linux.sh`

也可手动执行：

```bash
python3 serve.py
```

修改 `src/main.js` 后再运行：

```bash
pnpm --filter archive-of-the-ninth-tide-shoreless-layer build
```

`dist/` 与其中的 `app.js` 都是可再生成、不会提交的产物。`archive.mp3` 的唯一正本位于本目录；仓库根目录的 `pnpm exhibits:build` 会把完整 `dist/` 替换发布到 `public/exhibits/ninth-tide-archive/`，请勿直接编辑该 public 目录。

## 操作

- 拖动：环视
- 滚轮：潜航 / 后退
- 点击核心：展开或收束档案层
- 点击空间：发出当前章节的声呐
- `Space`：播放 / 暂停
- `M`：静音
- `F`：全屏
- `R`：重置镜头

## 九章视觉乐谱

章节边界来自音乐的节拍同步结构变化，并非平均切分。

| 时间 | 章节 | 中央能量体 | 点击声呐 |
|---|---|---|---|
| 0:00–0:49 | I · 无月测深 | 低频驱动的压强呼吸球 | 三维球形波壳 |
| 0:49–1:15 | II · 盐星下沉 | 九束盐星丝状放射 | 纵向声场帘幕 |
| 1:15–1:43 | III · 石英梦语 | 方向量化的石英切面 | 多边晶体辐条 |
| 1:43–2:25 | IV · 门后之海 | 被压窄的垂直能量柱 | 环形频谱柱阵 |
| 2:25–3:04 | V · 未诞之城 | 九瓣预测结构 | 三维点阵扩张 |
| 3:04–3:45 | VI · 逆潮遗骸 | 互相逆转的双重螺旋 | 双螺旋回波 |
| 3:45–4:20 | VII · 黑水密卷 | 压缩成不可读书页的点云 | 九层线框档案页 |
| 4:20–5:30 | VIII · 深渊回视 | 扁平虹膜与静止瞳孔 | 从远处向点击点收束的波壳 |
| 5:30–5:54 | IX · 无岸长夜 | 逐步冷却的档案珍珠 | 向内收缩并抹去局部光线的暗核 |

章节切换持续约 2.85 秒：旧形态先被压成一层球形光学记号，颜色与几何在最亮处交换，新章节再以自身的声呐语法从光膜中生成。

## 深海空间

- **近景散焦层**：大尺寸低透明粒子贴近镜头漂移，模拟灯前悬浮物与失焦回散。
- **档案层**：线框单元内部填充高密度点云，频谱分别控制位移、粒径、亮度和余辉。
- **远端骨架层**：大尺度结构只在声呐到达时短暂显影，避免形成清晰的舞台边界。
- **无岸暗场**：反面渲染的球形场、指数雾、外围多采样模糊、色散和噪声溶解共同抹去地平线。
- **压强层**：尺度巨大的稀薄环带以极低速度运动，提供无法准确测距的纵深参照。

## 开场与熄灭

开场由音乐时间直接驱动：三次不同语法的探测回波先建立空间，随后柱阵索引九室、点阵点亮核心，最后由收束波壳完成“回视”。屏幕文字只保留四句短暂铭文，视觉演出本身承担叙事。

终曲最后 13.6 秒不是整体淡出：远层先沉默，声呐反向收回，九台谐振器逆序停摆，档案点云折回中心；最后一粒光保留短暂残像，然后切入纯黑。

## 技术结构

- Three.js 0.184.0
- Web Audio `AnalyserNode`
- 64 段对数频谱 `DataTexture`
- GLSL 点云形变、线框共振与声呐材质
- `EffectComposer`、`UnrealBloomPass`、`AfterimagePass`
- 自定义外围溶解、色散、章节压强转场与暗核后期

移动端会降低档案数量、粒子数、几何细分和像素比。建议使用最新版 Chrome、Edge、Firefox 或 Safari，并启用硬件加速。
