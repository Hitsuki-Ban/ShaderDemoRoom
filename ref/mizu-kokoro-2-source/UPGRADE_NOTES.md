# 2.0 Upgrade Notes

## 目标

把 1.0 的“动漫液体球”提升为具有明确水感、物性差异、表面输运、相变结构和生命性回弹的技术展品。

## 主要变更

- 新增四套流变参数：黏度、表面张力、浪涌、流速、湍流、泡沫、清澈度、弹性、恢复、剪切。
- 新增球面切向流场和双相错位输运。
- 新增离屏场景颜色缓存、液体屏幕空间折射、色散与背面吸收壳。
- 新增台座动态焦散。
- 新增波峰 / 导数泡沫。
- 新增独立低多边形晶体外壳、局部晶核传播、cellular 裂纹、内部裂纹线段、晶片和气泡。
- 拖拽从单一法向隆起升级为法向 + 切向剪切 + 负压肩部 + 对侧收缩。
- 释放加入二阶回弹、切向甩动和传播回弹波。
- 实验面板新增“表面流线”和“回弹活性”。
- 相位栏新增流变类型、物性指标和 LIQUID / CRYSTAL 状态。
- 修复加载遮罩透明后仍可能截获指针的缺陷。
- 禁止展品拖拽时原生文本选择和页面过度滚动。

## 非目标

- 不实现完整 Navier–Stokes 或 SPH 流体求解。
- 不实现光线追踪多次折射。
- 不追踪真实气液界面泡沫。
- 不引入外部模型、纹理、字体或音频依赖。

## 回归验证

- `pnpm --filter anime-liquid-orb-exhibit build` 通过。
- WebGL2 液体主 shader 运行通过。
- 晶体 shader 首次显现通过。
- 四相位切换、塑形、冻结和 UI 状态更新通过。
- 加载遮罩退出后的真实指针命中通过。
