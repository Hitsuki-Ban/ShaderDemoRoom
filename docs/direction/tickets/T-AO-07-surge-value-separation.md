# [T-AO-07] SURGE の実効値分離を計測し単一パレット調整を決定する

- 分類: AD
- 優先度: P3
- 評価軸: 値構造 / 4相の判別性
- 依存: T-AO-03(profile/baseline gate)

## 現状(証拠)

コードの SURGE は deep `#1b0923` / mid `#ec3b9b` / light `#fff7df` / accent `#ffb72f` だが、既存批評は実効画面を「muted lavender-gray」と記録し、4相で最も値分離が弱いと評価する。パレット定数とトーンマップ後の画面の差は未計測である。

## 本票の唯一の結果

**showroom と standalone の実効色を測定し、必要なら modes 配列の1つのパレット変更だけで SURGE のグレースケール分離を成立させる。**

## 実施内容

1. 同じ状態・露出で showroom / standalone をキャプチャし、オーブ、背景、dais の実効色とグレースケール値を記録する。
2. トーンマッピング、bloom、屈折 tint のどこで値差が失われるかを切り分ける。
3. 調整が必要なら `modes` 配列を唯一の情報源として、測定で特定した1パレット値だけを変更する。shader 定数や別経路に補正を追加しない。

## 受け入れ基準

- before/after キャプチャと測定値が保存され、齟齬の原因が特定されている。
- 調整後、SURGE のオーブ/背景/dais がグレースケールでも分離し、CALM/BLOOM/VOID とサムネイルで判別できる。
- 4相 × freeze の回帰比較と `qa:visual` が通る。
- 調整不要の場合も、測定値が既存の意図を満たすことを独立レビューで確認して票を閉じる。

## 影響範囲・注意

- 改修する場合は ref/ 側で行い exhibits を再生成する。
- 複数の色、rim、露出を同時に動かさない。最初の変更が基準を満たさなければ、票を更新して再レビューしてから次の単一変更を選ぶ。
