# [T-GO-04] 光路を物理化する(レイ×球交差 + reflect()/refract())

- 分類: TA
- 優先度: P2
- 評価軸: モデル一貫性 / 描画正当性(教育展示としての正しさ)
- 依存: T-GO-01(ビームジオメトリの固定トポロジー化と実装を共有 — 先行した方の設計に他方が載る)。T-GO-05 は本チケットの経路計算を 3 波長で再利用するため本チケットが先行。T-GO-03 の着地点 uniform は本チケット完了後に物理値へ差し替え

## 現状(証拠)

- **入射ターゲットが球の内部にハードコード**: `src/rooms/glass-optics/runtime.ts:95` — `incomingEnd = new Vector3(0, 1.18, 0)`。ガラス球は中心 (0, 1.25, 0)(glassGroup `runtime.ts:226`)・半径 1.35(`IcosahedronGeometry(1.35, 8)`、`runtime.ts:230`)なので、**ターゲットは球面から 1.28 内側の球内部**。入射ビームは表面に接触せず内部で終端し、targetMarker(`runtime.ts:360`)が球内に浮く(dossier リスク 1)。
- **反射が法線反射ではない**: `runtime.ts:97-99` — `reflected = incomingEnd + vec3(-dir.x, abs(dir.y), -dir.z) * 3.6`。成分ミラーフリップのヒューリスティックで、球面法線とは無関係。光がターゲットより下から入る配置や lightZ 負では幾何的に誤った経路を描く。
- **屈折が 2 セグメントのフェイク**: `runtime.ts:100-105` — `refractedA = incomingEnd + direction * (1.4 / ior)`(※ `direction.multiplyScalar` が in-place 変異、dossier リスク 9)、`refractedB = (refractedA.x + beamSpread*2.4, 0.04, refractedA.z - beamSpread*3.2)`。Snell 則と無関係で、**IOR スライダーの見た目の効果は内部セグメント長 1.4/ior(1.4→0.58 world units)の微妙な伸縮のみ**。着地点は形状無関係に常に y=0.04。
- **従属要素がすべてフェイク値に連動**: markers(`runtime.ts:360-362`)、caustics 位置/スケール(`runtime.ts:113-118, 363-364`)が上記ヒューリスティックの出力を参照している。
- **現行テストはフェイク仕様を挙動固定**: `runtime.test.ts:40-53` が `calculateGlassLightPath` の `refractedB.y ≈ 0.04` と caustics 中点計算を expect している(挙動ベース化済みだが、固定しているのは旧仕様)。

## 問題

「屈折の振る舞いを読める教育デモ」というコンセプト(dossier「コンセプト」節)に対し、描かれる光路が物理と無関係のため、光源を動かしたときの応答が嘘になる。ビームが球に触れないままマーカーが宙に浮く様子は、注意深い観客ほど「壊れている」と読む。IOR という主役パラメータの体感効果が乏しい根本原因でもある。

## 改善方向

research-glass-optics.md §2.2 の閉形式計算(すべて CPU/JS、設定更新時のみ実行、描画コスト増ゼロ)を `calculateGlassLightPath` の置き換えとして実装する。

1. **レイ-球交差**: レイ `p(t) = s + v t`、球(中心 C=(0,1.25,0)、半径 r=1.35)で二次方程式を解き、小さい正根を入射点 P₁ とする。判別式 < 0(ビームが球を外れる)の場合は球中心へ照準を補正するフォールバックを実装する(スライダー範囲 lightX/Z ±6, lightY 0.8-6 では外れ配置が実際に発生し得る)。
2. **反射**: 入射点法線 `n₁ = (P₁−C)/r` に対し `Vector3.reflect()` を使用。反射ビームの不透明度は Schlick 近似 `F = F₀ + (1−F₀)(1−cosθ)⁵`、`F₀ = ((1−ior)/(1+ior))²` で変調し、掠り角で反射が強まる教材的に正しい挙動にする(現行の roughness 連動 `runtime.ts:378-379` はフレネル項との積に再定義)。
3. **屈折(入射→内部→出射)**: GLSL `refract()` 相当を自前実装(`k = 1 − η²(1−(n·i)²)`、k<0 ガード付き。周囲より高屈折率の球では外→内→外で全反射は起きないため実質フォールスルー)。内部レイの 2 回目交差(大きい根)が出射点 P₂、出射側は η を逆数にして再屈折。
4. **床着地とコースティクス連動**: 出射レイ×床平面 y=0 の交差 `t = −P₂.y / d.y` を着地点とし、`d.y ≥ 0`(床に届かない)ではコースティクスをフェードアウト。caustics 板の中心・楕円伸長(入射角の浅さ)・輝度(フレネル透過率)をこの計算に従属させ、T-GO-03 のホットスポット uniform に物理着地点を渡す。
5. **ビーム構造の再配線**: 経路は「光源→P₁」「P₁→反射方向」「P₁→P₂(球内)」「P₂→床着地」の直線 4 区間になる。T-GO-01 の固定トポロジージオメトリ(直線前提なら CylinderGeometry 変換が最良)にそのまま載せる。マーカーは P₁ / P₂ / 床着地点に配置し、「浮いたマーカー」を根絶する。
6. **`direction` の in-place 変異解消**: 新実装では中間ベクトルを clone または一時変数で扱い、入力を変異させない(dossier リスク 9 をここで吸収)。

## 受け入れ基準

- **数値基準(挙動テスト)**: `calculateGlassLightPath`(または後継 API)に対し、(1) `|P₁ − C| ≈ 1.35` / `|P₂ − C| ≈ 1.35`(表面接触)、(2) 床着地点の y ≈ 0、(3) ior を 1.0→2.4 に掃引したとき屈折角が単調に変化し ior=1.0 で直進(P₂ 以降が入射方向と一致)、(4) 反射ベクトルが `Vector3.reflect` と一致、(5) 球を外れる光源配置でフォールバックが働き NaN を出さない — を vitest で固定する。
- **視覚基準**: デフォルト・Focus beam・Crystal preset・極端配置(lightX=−6 / lightY=0.8 / lightZ=−6)の各キャプチャで、入射ビームが球表面で終端し、マーカーが表面/床上にあり、ビームの折れ方が直感的な屈折(入射より法線側へ曲がる)を示すこと。
- **応答性**: IOR スライダー操作で屈折ビームの角度・着地点・コースティクス位置が目視で明確に変化すること(現行の「セグメント長の微妙な変化のみ」からの脱却をビフォー/アフター動画またはキャプチャ列で記録)。
- **回帰なし**: draw calls 19 維持、FPS ±5% 以内(計算は設定更新時のみ)、`pnpm qa:visual` 通過。
- **プリセット再検分**: `glassOpticsFocusPreset` / `glassOpticsCrystalPreset`(`state.ts:33-45`)の構図が新経路で成立するよう値を再調整し、キャプチャで承認を得ること。

## 影響範囲・注意

- **挙動テストの書き換え**: `runtime.test.ts:40-53` は旧フェイク仕様(refractedB.y=0.04、中点 caustics)を固定しているため、上記の物理性テストへ全面置換する。テスト更新は本チケットのスコープに含める。
- **T-GO-01 との実装共有**: ビームジオメトリの持ち方は T-GO-01 と同一箇所(`updateBeamGeometry` / `createTubeGeometry`、`runtime.ts:57-65, 122-127`)。先行チケットの構造に載せ、二重改修を避ける。
- **beamSpread の暫定的意味**: 現行の refractedB 横オフセット(`runtime.ts:101-105`)が消えると beamSpread の主効果が失われる。本チケットでは暫定的に「コースティクス集束度 + ビーム/光源の演出変調」(`runtime.ts:376-383` の既存連動)に留め、**T-GO-05 で「分散誇張率」として正式に再定義**する。スライダーを無効化しないこと(URL スキーマ `src/shared/url-state.ts:79` に beamSpread が載っており、キー削除は URL 互換を壊す)。
- **プリセット・URL 互換**: 設定キーの型・レンジは変えない(`glassOpticsDomains`、`state.ts:8-19`)。値の意味変化のみで、URL 復元(T-SH-05)はそのまま機能する。
- **特異配置**: 光源が球の真上/真下に近い配置での急変(research §2.2 リスク)は、フォールバック照準+補間なしの許容とし、受け入れキャプチャに極端配置を含めて破綻がないことだけ確認する。
